# pushup_plank (cz. 2) — role mięśni, fala W2 (badacz-merytoryczny, 02.11.2026)

Zakres: luki z W1 (`role-miesni-fala-w1/pushup_plank.md`, gałąź `badania/g5-pchanie`) poza ćwiczeniami pompek z cz1 — deski, rollouty,
Suspended Fallout, Copenhagen Plank, Plank Shoulder Taps, Mountain Climbers, Renegade Row. Propozycje W1 „gotowe” (Side Plank,
Copenhagen obliques, Push Up to Side Plank — `obliques.side_hold`) nie badane ponownie.

## Wynik

Nowych reguł `nameRules` w W2: **0**. Wszystkie luki zostają otwarte — w W2 nie znalazłem przeczytanego źródła, które przypisuje
funkcję wprost (wariant A wymaga funkcji, nie samej aktywności EMG).

## Następny krok

- `abs.antilordosis`: podręcznik kinezjologii albo przegląd szczebla 2–3 o mechanice ćwiczeń przeciw wyprostowi (np. przeczytać PMC3157598 i sprawdzić, czy opisuje funkcję mięśnia, nie tylko model stabilności). StatPearls (captcha) i Physiopedia (403) niedostępne.
- Opór przed skrętem: źródło szczebla 2–3 nazywające skośne brzucha w ćwiczeniach anty-rotacyjnych.
