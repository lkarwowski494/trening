# Podglądy poprawek po recenzji ruchu 1.1, partia 1

Podglądy 16 zmienionych ćwiczeń (poza poprawna + wiersz błędu; rzut z boku i z przodu, u = 0 / 0,5 / 1), rysowane z póz zapisanych w `lib/figures/v2/poses/` na gałęzi `poprawki-p1` (skrypt `htmlPodgladu` / kształty silnika v2, bez regeneracji z generatora).
Tabela kątów stawów: `katy-stawow.md`. Nie recenzuję własnej pracy: pliki są materiałem dla niezależnego recenzenta.

Ćwiczenia: Ring Dips, Arnold Press, Kettlebell Arnold Press, One Arm Row (hantle), Wide-Grip Rear Pull-Up, Scapular Pull-Up, Dead Hang, Concentration Curl (hantle), Tate Press, Reverse Pec Deck, Chest Fly (hantle), Incline Chest Fly (hantle), Decline Dumbbell Fly, Flat Bench Cable Fly, Incline Cable Fly, External Rotation (hantel).
