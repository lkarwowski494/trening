## Pominięte jako teoretyczne (CLAUDE.md, „Audyty i wydania” pkt 6)

| Przepływ | Powód |
|---|---|
| Ręczna edycja pliku bazy lub kopii w edytorze, a potem otwarcie w aplikacji | Teoretyczne: wymaga zmiany danych poza aplikacją; format chronią migracje i walidacja importu (testy Jest). |
| Brak miejsca na dysku telefonu podczas zapisu | Teoretyczne w normalnym użyciu; zapis jest atomowy (SQLite), a błąd startu bazy ma ekran awaryjny (PR-16). |
| Synchronizacja z drugim urządzeniem lub iCloud | Aplikacja jest lokalna (ADR), funkcji nie ma. |
| iPad, Stage Manager, kilka okien aplikacji | Aplikacja na iPhone’a; układ iPada nie jest wspierany. |
| Wejście przez link głęboki (trening://…) ze zewnętrznej aplikacji | Brzegowe i bez drogi z UI; ekrany otwarte linkiem zawsze mają zakładki pod spodem (unstable_settings), sprawdza test routingu. |
